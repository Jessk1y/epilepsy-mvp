# Как запустить «ЭпиАссистент» у себя

Демо-режим работает на любом ноутбуке без видеокарты и без моделей. Все данные в нём синтетические, с пометкой «ДЕМО». Нужен Python 3.10 или новее и доступ к репозиторию `epilepsy-mvp` на GitHub.

## 1. Получить код

Репозиторий уже есть:

```bash
cd epilepsy-mvp
git pull
```

Репозитория ещё нет:

```bash
git clone https://github.com/Jessk1y/epilepsy-mvp.git
cd epilepsy-mvp
```

## 2. Поставить пакеты (один раз)

Лучше в отдельное окружение, чтобы не смешать с другими проектами.

**Windows (PowerShell):**

```bash
py -m venv .venv-app
.venv-app\Scripts\activate
pip install -r app/requirements.txt
```

**macOS / Linux:**

```bash
python3 -m venv .venv-app
source .venv-app/bin/activate
pip install -r app/requirements.txt
```

Ставятся fastapi, uvicorn, numpy, scipy, nibabel, а для тестов — pytest, httpx, scikit-learn, pandas. Всего около 150 МБ. Папка `.venv-app` в git не попадает.

## 3. Запустить

```bash
python app/run.py --demo
```

На Windows без окружения — `py app/run.py --demo`.

Открыть в браузере: **http://127.0.0.1:8000**. Остановить — `Ctrl+C` в терминале.

В следующие разы: активировать окружение (шаг 2, вторая строка), сделать `git pull` и выполнить шаг 3.

## 4. Проверить, что всё в порядке (по желанию)

```bash
python -m pytest app/tests -q
```

Около 2 минут, все тесты должны пройти.

## Если не работает

| Что видно | Что делать |
|---|---|
| `No module named fastapi` | Не активировано окружение (шаг 2, вторая строка) или не поставлены пакеты |
| `Address already in use` / порт занят | `python app/run.py --demo --port 8001` и открыть `http://127.0.0.1:8001` |
| `git clone` спрашивает логин или «Repository not found» | Нет доступа к репозиторию — попросить Захара добавить в GitHub |
| Страница открылась, но пустая | Обновить страницу с очисткой кэша (`Ctrl+F5`) |

## Настоящие модели (рабочая машина)

С моделями приложение запускается только на рабочей машине: там веса, данные и видеокарта (раздел «Запуск в боевом режиме» в `README.md`). Если Захар запустил его там, любой, у кого есть SSH-доступ к этой машине, может открыть его у себя через проброс порта:

```bash
ssh -N -L 8000:127.0.0.1:8000 <ваш_логин>@<адрес рабочей машины>
```

Затем открыть **http://127.0.0.1:8000**. Окно с `ssh` держать открытым.
