# TUEP: дообучение REVE v4 по 5 фолдам (14.11.2026)

Код: `h1_eeg/tuep/tuep_finetune.py` (схема — `Ревью/Ревью_TUEP_2026-11-14.md`, раздел 3). 5 фолдов × 3 запуска, старт с весов REVE v4 после NMT, выравнивание слоёв монтаж|частота между классами, ФНЧ 45 Гц, ранняя остановка по отложенному фолду. 199 пациентов, один случайный сеанс без приступов (seed 0). Рабочая машина (RTX A5000), 66 мин. Здесь только сводные цифры.

Первый фолд (40 пациентов) давал 0,725 и 0,778 внутри слоя — по всем фолдам это не подтвердилось.

## Вывод

Дообученная REVE v4 **не превзошла простой эталон** ни в общем ROC AUC (0,592 против 0,625), ни внутри слоя (0,555 против 0,578), ни на 01_tcp_ar (0,585 против 0,611). По правилу ревью 14.11 («оставлять, только если выше эталона внутри слоёв») не принимается; EEG-DINO v2 по тому же правилу не дообучали. На TUEP различение эпилепсии и других пациентов по одной рутинной записи в наших руках — около 0,6 (лучший — эталон 0,625), ориентир 0,76 не достигнут.
