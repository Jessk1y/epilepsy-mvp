# Имена блокнотов и журнал экспериментов

## Имя блокнота

```
<гипотеза>_<ГГГГ-ММ-ДД>_<автор>_<кратко-латиницей>.ipynb
```

- гипотеза: `h1` (ЭЭГ) или `h2` (МРТ);
- дата — день начала эксперимента;
- автор — инициалы латиницей (Захар Санников — `zs`; остальным — две буквы, договоримся и допишем сюда);
- кратко — 2–4 слова через дефис: модель и данные.

Примеры: `h1_2026-10-20_zs_deepepilepsy-turkish.ipynb`, `h2_2026-10-27_zs_nnunet-bonn.ipynb`.

Правила:
- без пробелов и кириллицы в имени файла (иначе ломаются Kaggle, Linux и git на Windows);
- **один блокнот — один автор.** Чужие блокноты не правим; хотите продолжить — копируйте под своим именем и укажите источник в шапке;
- новая идея = новый блокнот, а не бесконечная правка старого: так журнал и история остаются честными;
- блокнот лежит в `h1_eeg/notebooks/` или `h2_mri/notebooks/`.

## Журнал экспериментов (`experiments_log.md`)

Одна строка на завершённый эксперимент, добавляется **сверху таблицы** в том же pull request, что и блокнот.

| Колонка | Что писать |
|---------|-----------|
| Дата | дата завершения |
| Автор | инициалы |
| Гипотеза | Г1 / Г2 |
| Модель | название и откуда веса |
| Данные | набор и число пациентов по классам |
| Метрика | главная метрика с доверительным интервалом и уровнем (пациент / кусок) |
| Блокнот | относительная ссылка на файл |
| Вывод | одно предложение: что узнали, в том числе «не сработало» |

Пример строки:

```
| 2026-10-20 | ЗС | Г1 | DeepEpilepsy, готовые веса | Turkish-epilepsy, 50+71 пациент | ROC AUC 0,xx (95% ДИ …), пациент | [блокнот](h1_eeg/notebooks/h1_2026-10-20_zs_deepepilepsy-turkish.ipynb) | Одно предложение |
```

Отрицательные результаты тоже записываем — это часть отчёта.
Итоги по гипотезе (1–3 строки) обновляем в `h1_eeg/SUMMARY.md` и `h2_mri/SUMMARY.md`.
